# SQL Joins & Relationships 🗄️

A beginner-friendly SQL project focused on understanding **One-to-Many relationships** and practicing different JOIN operations to retrieve data from multiple related tables.

## Concepts Covered
- Primary & Foreign Keys
- One-to-Many Relationships
- INNER JOIN
- LEFT JOIN
- RIGHT JOIN
- FULL OUTER JOIN

## Purpose
To strengthen my understanding of SQL joins and relational database concepts through hands-on practice.
