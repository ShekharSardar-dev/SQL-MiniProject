# SQL Joins & Relationships 🗄️

A beginner-friendly SQL project focused on understanding database relationships and retrieving data from multiple related tables using different JOIN operations.

## 📚 Concepts Covered

- Primary Keys & Foreign Keys
- One-to-One Relationships
- One-to-Many Relationships
- Many-to-Many Relationships
- INNER JOIN
- LEFT JOIN
- RIGHT JOIN
- FULL OUTER JOIN
- Table Relationships

## 🎯 Purpose

The purpose of this project is to strengthen my understanding of SQL, relational databases, and data retrieval through practical queries.

## 🛠️ Technologies Used

- SQL
- Relational Database Management System (RDBMS)
